# MCP を使うデータ分析エージェント

## 1. 対象

指標と文書を利用して質問に答える構成例。利用者の権限と検索結果の範囲を確認する。

## 2. 機能配置

利用者が質問し、エージェントが権限を確認する。指標ツールは分析データを問い合わせ、文書検索は関連文書と出典を返す。実行を記録し、担当者が結果を評価する。認証連携とアクセス権は採用環境に合わせて実装する。

## 3. 実装例

各機能の担い手を示す。実行履歴の記録範囲と保持方針を設定する。

| 機能 | 担い手 |
