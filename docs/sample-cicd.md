# CI/CD パイプライン設計書（サンプル）

> DeepDiverDown の動作確認用の架空の設計書。

## 1. 概要
GitHub の main ブランチへの push を起点に、ステージングを経て本番へデプロイする。

## 2. 開発者
決済チームの開発者（5 名）がプルリクエストをマージし、main に反映する。

## 3. ビルドとテスト
CodeBuild でコンテナイメージをビルドし、ユニットテストと脆弱性スキャンを並列で行う。
両方を通過したイメージだけを ECR に登録する。

## 4. リリース承認
ステージングでの E2E テスト通過後、テックリードが承認する。承認後に本番へデプロイする。

## 5. 監視
本番の ECS のメトリクスを CloudWatch で監視し、異常時は運用当番に通知する。

## 6. 目標
main への push から本番反映まで 30 分以内。
