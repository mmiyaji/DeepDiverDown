# H3：セル ID・階層・集計

## 1. 対象と入力

H3Index は 64 ビット整数で、mode はセル、辺、頂点などを区別する。セルモードには解像度、基底セル、階層を表す桁が含まれる。文字列はこの整数の 16 進表現であり、DB インデックス構造そのものではない。

## 2. 保存と読み出し

H3 は全球を複数解像度のセルに分ける。各解像度には 12 個の五角形が含まれ、単純な六角形だけの格子ではない。同じ解像度のセル ID を使って集計・結合する。h3-py 4.x は latlng_to_cell(lat, lng, res) を用いる。

## 3. 制約と運用

親子関係は論理インデックスとして厳密だが、解像度の違うセル同士の地理的な包含は近似。セルの一致だけで距離やポリゴン内の厳密な一致は保証されない。境界付近を含む候補生成を設計し、必要なら元座標と正確な空間述語で再判定する。

## 4. 実装例

利用者が Linux 上の Python 内で h3-py を使い、座標をセル ID に変換してファイルを集計する。厳密な境界判定は別途実装する。 この図は公開資料に基づく代表的な構成であり、特定環境での実行や耐障害性を検証した導入事例ではない。設定とバージョンにより挙動は変わる。
