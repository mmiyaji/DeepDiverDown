プライバシーポリシー

本サイトには、アカウント登録や個人情報の入力欄はありません。

設定、表示中の状態、ブラウザに読み込んだモデルは、お使いのブラウザ（localStorage・sessionStorage）にだけ保存し、作者のサーバーへは送信しません。ブラウザの設定からいつでも削除できます。

アクセス解析や広告の仕組みは使っていません。ただし、公開サイトは Cloudflare Pages で配信しており、配信にあたって IP アドレスなどのアクセスログが Cloudflare 側で処理される場合があります。

他のサイトへのリンクがあります。リンク先での情報の扱いは、各サイトの方針に従います。

この方針は機能の追加などに合わせて変更することがあります。変更は更新履歴に記載します。お問い合わせは GitHub の Issuesへお願いします。
